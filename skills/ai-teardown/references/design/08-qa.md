# 08 · 质检门

四道门，按「事实 → 教学 → 画面 → 音频」的顺序过。前一道不过，不进下一道。

## 事实门（`scripts/check.py`）

| 检查 | 阈值 | 不过怎么办 |
|---|---|---|
| 每条事实的摘录在快照里逐字找得到 | 0 缺失 | 回快照重新复制原文 |
| `verified` 至少一个 T1 或两个 T2；讲机制必须有 T1 | 0 违规 | 补证，或降级为 `inferred` / `undisclosed` |
| `show/name/place/compare/recap` 的 beat 都挂了事实 | 0 缺失 | 补事实引用 |
| 旁白里的每个数字都在所引事实里 | 0 缺失 | 改稿或补事实 |
| 推断、未披露的事实按诚实编码处理 | 0 违规 | 画面标 `inferred/undisclosed`，或旁白明说 |

## 教学门

| 检查 | 阈值 | 工具 |
|---|---|---|
| 讲稿结构：beat 数、每 beat 都有 `move`、画面、事实 | 全部具备 | `check.py`（模型常交「格式合法但内容不达标」的稿，InkFlow 踩过） |
| 每 beat 至多一个新概念；先修已讲 | 0 违规 | `check.py` |
| 预计时长与目标偏差 | ≤ 15% | `check.py` |
| 冷读盲测 | ≥ 4/5 | 子 agent（见 `06-pedagogy.md`） |

## 画面门

| 检查 | 阈值 | 工具 |
|---|---|---|
| 文字溢出、被遮挡、互相重叠 | 0 问题 | `hyperframes inspect`（按时间轴采样，Spike 已调到 0） |
| 文字对比度 | 全部 WCAG AA | `hyperframes validate` |
| 过渡中间帧（不只看静止态） | 人工过一遍接触表 | `scripts/stills.py` 在每个状态切换后 0.05 秒各抽一帧 |
| 语画同步：cue 时刻与画面动作 | ≤ 0.2 秒 | 状态切换取 cue 时刻并对齐到 0.25 秒网格 |
| 确定性：同一时刻从不同方向 seek | DOM 严格一致；像素差异像素 ≤ 0.01% | Spike 里的确定性脚本（将并入 `scripts/`） |
| 引擎一致性（启用 Remotion 兼容轨时） | 两边成片逐帧 SSIM ≥ 0.98 | ffmpeg `ssim` |

## 音频门

| 检查 | 阈值 | 工具 |
|---|---|---|
| 整体响度 | -14 ± 1 LUFS | `scripts/mix.py` 末尾的 ebur128 报告 |
| 真峰值 | ≤ -1.5 dBTP（混音按 -2.0 留余量） | 同上 |
| 背景乐在旁白下让位 | 旁白时背景乐约压低 8 dB | `sidechaincompress` |
| 读音 | 读音词典命中；新专有名词人工听一遍 | `lexicon.json` |

Spike 实测：单遍 `loudnorm` 落在 -15.3 LUFS，差 1.3 LU；`mix.py` 改为两遍（先测量、再按测量值线性归一）后为 -14.4 LUFS、真峰值 -1.5 dBFS，达标。
