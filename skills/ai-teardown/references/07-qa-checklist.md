# 07 · 质检清单

## 配音后（voice.log）
- [ ] 每拍回读 ≥ 95%，无「⚠ 可疑读数」；低的删 `build/audio/<拍>.*` 重合成，两次仍低就改措辞。
- [ ] 人名、产品名、缩写、版本号用 whisper-cli 复听过（必要时加 `--prompt "专名"`）。
- [ ] 没有多念、重复、漏念或多出的否定词。
- [ ] 全节时长落在目标区间（build 输出「总长」）。

## 编排后（build 接触表 + 单帧）
- [ ] `check_scenes.py` 零报错（「只有 x 秒」也要修）。
- [ ] 先 `rm -rf build/stills` 再 build（旧帧会混进接触表）。
- [ ] 无文字溢出、重叠、折行拆词；recap 中心字在椭圆内。
- [ ] 截图圈注对准；截图不糊、不太小。
- [ ] 小人气泡不挡关键文字；出处小字不被 caption 压住。
- [ ] 无空屏（场景第一个元素尽快出现）。
- [ ] 镜头推拉时不裁掉卡片（接触表里的「半张卡」可能只是运镜中间帧，单帧确认）。
- [ ] 动画类要看中间帧，不只看静止态（重影、残留常在转场中间）。
- [ ] 开头接上一节、结尾预告下一节 + 致谢，与 series.json 标题一致。

## 隐私与版权（见 09-safety）
- [ ] 截图/录屏里无人名账号（书作者署名可留）、手机号、二维码、邮箱、密钥、Token、本机用户名路径、公司内部名。
- [ ] 录屏跑过 `rec_scan.py`。
- [ ] 引用逐字、标章节；示意数据标「示例数据」；投资类内容写「不构成投资建议」、不念个股名价格评级。

## 成片后
- [ ] 时长与 build 总长一致。
- [ ] 抽 6 帧（开头、中段、结尾）拼图看：无黑帧、无残留层、字幕正常。
- [ ] 互动版文件清单只含本节用到的图（`sketch_publish_files.py`），名字含「:」的已跳过。
- [ ] 发布后把 MP4 发给用户，记录链接。
