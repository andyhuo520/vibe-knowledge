# 01 · 流程与确认点

## ① 查：收集资料

- 信源分级：**T1** 官方文档 / 原书 / 官方仓库；**T2** 权威媒体、论文、博物馆与百科；**T3** 社区教程、博客（只作线索，要回到 T1 核对）。
- 每条事实记：原文句子、来源 URL、日期、等级。数字、价格、模型名写明「截至某日」。
- 研究产物放 `examples/<系列>/research/`：`landscape.md`（综述 + 2–3 套大纲草案）、`facts.json`。
- 题材是一本开源书 / 仓库时：`git clone` 到 `examples/<系列>/source/`，章节图片用 `scripts/wb_import.py` 导入（见 06-visual-assets）。
- 读不到的站点：GitHub 代码块用 raw 链接；部分官网只能浏览器读；视频站本机常打不开，别假装看过。

## 确认 1：对象、课时、音色、画风

一次问清，给推荐项：
- **对象**：零基础大众 / 会一点电脑的职场人 / 开发者。
- **课时**：节数 × 每节分钟（实测 4–7 分钟最舒服；1.15 倍速后每秒约 5 字）。
- **音色**：先用 `scripts/voice_audition.py` 出 4–16 个试听给用户挑；定了之后用第一次生成的录音做克隆参照，全系列锁定（presets/voice/host-ref.wav 就是这样来的）。
- **画风**：先出 40–60 秒样片（同一段内容），不要只给描述。现有：Notion 极简手绘（sketch/notion）、手账纸（sketch/paper）、马卡龙 / 薄荷 / 夜间（lesson）。
- 拍板记进 `DECISIONS.md`。

## ② 纲：大纲与课程页

- `series.json.lessons[]`：`n, title, hook（一句引子，问句最好）, intro（这一节讲三件事）, points（4–6 条要点）, minutes`。
- 课程页先出草稿（`status: "draft"`、`status_label: "大纲待确认"`），每节显示「制作中」。
- 长章节（1 万字以上）只挑最核心的 3 块讲；两短章可以合成一节；课外阅读类可做一节。
- 章节号以原书**目录名**为准（index.md 标题可能差 1）。

## 确认 2：用户看大纲

改完再开写。之后的「写」「编」可以批量并行。

## ③④ 写与编：多智能体分工

- 主会话：给每个助手一份自足的任务说明（课目录、标题、来源章节目录名、导入命令、前后节衔接的标题、隐私要求、已知模板限制），一次 3 个，后台跑。
- 助手：严格按系列目录的 `BRIEF.md` 做，只动自己的课目录；不渲染、不发布、不改引擎代码、不改 series.json；模板 bug 写进回报。
- 主会话收到回报后：复听可疑拍（whisper-cli）、重跑 build 看接触表、必要时自己改 scenes.json，再排进渲染队列，同时派下一节。
- 助手回报的「模板限制」要汇总成下一批任务说明里的「已知坑」，并尽快在引擎里修掉（修完对已排队但未渲染的课重跑 build——final 不会重跑 build）。

## ⑤⑥ 渲染与发布

见 02-pipeline.md。每出一节：抽帧质检 → 发互动版 → 把 MP4 发给用户 → 记进度。

## 确认 3：第 1 节成片

用户看第 1 节后的反馈往往会改模板（配色、动效密度、小人、图标来源），改完再批量。用户给的风格反馈都记下来，作为之后所有课的默认。

## 导学视频（课程地图）与课程总页

全部出完后补一支 2–3 分钟的导学：
1. 开场致谢（原作者 / 开源项目；用户点名感谢的人放最前，措辞与事实一致——多人作者写「作者之一」，并列出其他作者）。
2. 这是什么（原书/项目的一句话定位，逐字引用）。
3. 为什么学（和普通做法的对比 compare）。
4. 课程地图（按站/篇分组的 stickers 卡片，每张写节号范围 + 3 个关键词）。
5. 学完能掌握（numbered checklist，4 条）。
6. 怎么学（每节时长、暂停想一想、互动版、马上动手）。
7. 「我们第 0 节见」。

导学课目录可用非数字名（如 `lessons/intro`），scenes.json 写 `"videoOnly": true`（final 不找 series.json 课号、不做互动版）；封面用 `eyebrow` / `props` 覆盖「第 N 节」。课程页用 `series.json.sample`（heading、sub、video、poster、changes[{k,v}]）挂在顶部。

## 学习包（可选增强）

课程页每节卡片可加：学习目标 3 条（「学完你能……」）、本节思维导图（从 scenes.json 的 chapter/pan/recap 结构生成）、课后三问（可折叠答案）、动手练习（可复制的任务说明）、原文延伸链接；系列层面加总思维导图、按身份的学习路线、进度打勾。全部从旁白与原文派生，不另编。
