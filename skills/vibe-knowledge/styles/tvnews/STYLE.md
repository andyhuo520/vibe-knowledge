# 电视新闻包装 · TV NEWS

> 家族：剪辑与纪实　|　档位：基础档 · 0 积分　|　风格图：`still.jpg`　|　样片源码：`_samples/styles9_film.js → tvnews()`

**一句话**：蓝色演播室底、虚构台标「VIBE 新闻 · 直播」、画中画现场、两层下方标题条、底部滚动字幕，五十金红色「突发」横幅。

| 项 | 写法 |
|---|---|
| 导演意图 | 电视新闻的包装语法：画面在播、标题条在讲、滚动字幕在补充，突发横幅一砸下来就是高潮。 |
| 材质 / 画法 | 蓝色渐变 + 横向光带；台标块 + 直播红点；时钟；画中画（配图，标 AI 示意）；右侧数据面板；两层下方标题条（红标签 + 白标题 + 蓝副标题）；滚动字幕；全宽红色突发横幅。 |
| 配色逻辑 | 蓝 #06173A → #0B3A7A · 红 #E8202A · 白 · 深字 #0B1B33 |
| 字体 | Geist / PingFang 900 |
| 动态 | 画中画从左滑入；标题条红标签横向展开、白条揭开；滚动字幕匀速；数字滚动；高潮突发横幅 0.2 秒纵向展开。 |
| 镜头语法 | 锁定（电视画面）。 |
| 声音 | 新闻片头鼓点、提示音、突发音效。 |
| 标志镜头 | 全宽红色横幅「突发 · 赏金提至 五十金」。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：换台名（必须虚构）、换配色
- **一改就变味**：模仿真实电视台台标 / 配色 / 栏目名
- **不能改**：去掉出处（滚动字幕里写史料来源）

## 搭配
- 适合母版：两难选择 B、猜谜概念 A
- 不适合：诗词、治愈
- 增强档 Renoise 前缀：`（基础档不需要；画中画可复用增强档配图）`
