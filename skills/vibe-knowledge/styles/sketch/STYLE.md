# 手绘过程 · HAND-DRAWN PROCESS

> 家族：图解与设计　|　档位：基础档 · 0 积分　|　风格图：`still.jpg`　|　样片源码：`_samples/styles10_film.js → sketch()`

**一句话**：一只捏着铅笔的手一路画给你看：铅笔起稿 → 墨线描出 → 马克笔来回涂色 → 手写字，镜头跟着手走，最后拉远看全图。

| 项 | 写法 |
|---|---|
| 导演意图 | 白板 / 手绘讲解片（RSA Animate 式）：观众看的不是一张成品，而是「画出来」的过程，注意力被笔尖牵着走。 |
| 材质 / 画法 | 一张比屏幕大的米白纸（2600×1460）+ 细点纸纹；同一条 SVG 路径画两遍：先浅灰铅笔稿（偏移 3px、快速勾完），再黑色针管笔墨线按 dash 描出；手写字 = 楷体 + 从左往右展开的 clipPath；马克笔 = 形状 clipPath 里一条来回扫的 46px 粗笔触（multiply 叠色）；原创 SVG 手 + 黄杆红顶铅笔，笔尖固定在当前笔画的端点。 |
| 配色逻辑 | 纸 #FBF8F2 · 铅笔 #B9B2A6 · 墨 #23201C · 批改红 #D7392B · 马克笔：屋顶 #E46A4A / 金币 #F2C14E / 墙 #F3D9B4 |
| 字体 | 楷体 700（手写字） |
| 动态 | 铅笔稿 0.3 秒一条依次勾出 → 墨线按旁白顺序逐条描（每条 0.1–0.4 秒），手的笔尖用 getPointAtLength 跟着走；写字时手跟着 clip 边；停笔时手抬起 26px；上色按来回笔触推进；结尾手滑出画面。 |
| 镜头语法 | 白板式跟随：画在大纸上，镜头 0.42 秒缓动移到下一块区域，最后拉远到 0.66 倍看全图。 |
| 声音 | 铅笔沙沙、马克笔吱吱、翻纸；轻快木吉他或尤克里里。 |
| 标志镜头 | 手把「10」划掉，在上面用红笔写「50」，随后马克笔把金币和屋顶一笔笔涂满。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：换纸色（白板 / 牛皮纸 / 方格纸）、换笔色、换手的肤色和袖子
- **一改就变味**：一开始就出现完整线稿（失去过程）
- **不能改**：去掉手和笔（就变成普通线描动画了）

## 搭配
- 适合母版：痛点原理 C、闯关 E、一条主线 D
- 不适合：需要写实画面的选题
- 增强档 Renoise 前缀：`（基础档不需要）。手法参考 RSA Animate 等白板动画的公开做法，手、笔和画面均为原创`
