# 风格库（44 套 · 8 个家族）

一期片子 = **母版（讲法，references/01-templates.md）× 风格（长相 + 讲法，本目录）× 手法（≤2，references/12-style-families.md 第五节）× 档位（基础 0 积分 / Renoise 增强）**。
每套风格一个目录：`STYLE.md`（导演意图、材质、配色、字体、动态、镜头、声音、标志镜头、三分法、搭配）+ `still.jpg`（风格图）。样片源码在 `_samples/`，全部在 2026-10-27 用同一段开场（第 01 期 B01）渲染验证。
用户自己的风格存在 `~/vibe-knowledge-styles/<名字>/`（同样的结构），做片时排在最前面。改风格 / 新建风格的流程见 `references/09-style-studio.md`；家族划分、87 种 UI 风格怎么取舍、从 promo-video 借了什么、增强档踩坑见 `references/12-style-families.md`。
