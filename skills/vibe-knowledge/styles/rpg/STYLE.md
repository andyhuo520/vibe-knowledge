# RPG 对话框 · RPG DIALOGUE

> 家族：游戏　|　档位：基础档 · 0 积分　|　风格图：`still.jpg`　|　样片源码：`_samples/styles6_film.js → rpg()`

**一句话**：上方像素场景，下方深蓝对话框逐字打出，选项菜单里大家都停在「观望」，五十金光标跳到「搬」，弹出「获得 50 金！」。

| 项 | 写法 |
|---|---|
| 导演意图 | 把两难选择变成 RPG 里的选项：观众自然代入「我会选哪个」。 |
| 材质 / 画法 | 240×90 像素画放大 8 倍（天空色带、城门、村民、主角）+ 深蓝双边框对话框 + 名字牌 + 选项菜单 + 获得物品框。 |
| 配色逻辑 | 夜空蓝渐层 · 对话框 #141A46 · 白边 #F4F4F4 · 光标 / 获得 #FFD84A |
| 字体 | NotoSC 700–900（对话 56px） |
| 动态 | 22 字/秒打字；▼ 闪烁；菜单光标在选项间跳；获得框弹出；主角走过去扛起木头。 |
| 镜头语法 | 锁定。 |
| 声音 | 打字哔哔声、光标嘀、获得物品的小号音效；8-bit 配乐。 |
| 标志镜头 | 选项菜单「搬 / 观望」，光标停在「观望」——没人动。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：换场景、换名字牌
- **一改就变味**：对话框一次整句出现
- **不能改**：去掉选项（这是两难选择的核心）

## 搭配
- 适合母版：两难选择 B、闯关 E
- 不适合：纯数据
- 增强档 Renoise 前缀：`（基础档不需要）`
