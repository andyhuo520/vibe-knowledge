# 水墨纸本 · INK & PAPER

> 类别：视觉系统　|　风格图：`still.jpg`　|　样片源码：`_samples/styles_film.js → paper()`

**一句话**：宣纸底、晕染远山、一笔浓墨，宋体竖排配朱砂印。

| 项 | 写法 |
|---|---|
| 导演意图 | 雅致、慢慢读、有文化感。 |
| 材质 / 画法 | SVG：宣纸径向渐变 + feGaussianBlur 晕染远山 + feTurbulence 毛笔飞白 + 朱砂印章。 |
| 配色逻辑 | 纸 #f4eddc→#e2d6bc · 墨 #2a2420 · 朱砂 #b23a2e（全片唯一的彩色）。 |
| 字体 | 宋体 700 竖排为主，横排说明用 NotoSC 小字。 |
| 动态 | 墨线由下往上写出、竖排文字逐列出现、印章盖下（1.8→1）。 |
| 镜头语法 | 横向缓慢平移（像展开长卷）。 |
| 声音 | 古琴 / 箫 / 留白；翻纸、落印的轻音效。 |
| 标志镜头 | 朱砂印章盖在画面上；竖排诗句逐字显出。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：换印章文字、远山形状、竖排内容
- **一改就变味**：加饱和色彩（破坏纸本感）
- **不能改**：换成深色底

## 搭配
- 适合母版：D 一条主线片、F 六面轮转片、诗词类 A
- 不适合：科技、数据密集的题
- 增强档 Renoise 前缀：`Chinese ink wash painting on warm rice paper, sparse composition, soft grey washes, a single vermilion accent, no text, no seal`
