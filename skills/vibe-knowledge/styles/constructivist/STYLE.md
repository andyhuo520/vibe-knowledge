# 构成主义蒙太奇 · CONSTRUCTIVIST

> 家族：电影感　|　档位：基础档 · 0 积分　|　风格图：`still.jpg`　|　样片源码：`_samples/styles6_film.js → constructivist()`

**一句话**：米色纸、红黑斜线构图、半调剪影人群、标语大字沿斜线撞进来、喇叭放射线。

| 项 | 写法 |
|---|---|
| 导演意图 | 罗琴科式构成主义：斜线制造冲击，文字就是标语，像在喊出来。 |
| 材质 / 画法 | 米色纸 + 斜 12° 红带 + 黑色大圆 + 黑色斜梁 + 半调网点人群剪影 + 红色放射线。 |
| 配色逻辑 | 纸 #EFE6D2 · 红 #D7261E · 黑 #151311（高潮红黑互换） |
| 字体 | Geist / PingFang 900，大数字 420–460px 负字距 |
| 动态 | 所有元素沿斜线 eOutQuint 撞入（0.18–0.28 秒）；「没人动」竖排黑块从下顶上来；高潮红带变黑、黑圆变红。 |
| 镜头语法 | 锁定；构图本身倾斜。 |
| 声音 | 铜管、军鼓、扩音器回声。 |
| 标志镜头 | 「10」斜着撞进画面，红色喇叭放射线从右侧黑圆射出。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：换红色为别的单一强调色
- **一改就变味**：水平垂直构图（失去冲击）
- **不能改**：用柔和渐变

## 搭配
- 适合母版：两难选择 B、痛点原理 C
- 不适合：温情、治愈
- 增强档 Renoise 前缀：`（基础档不需要）`
