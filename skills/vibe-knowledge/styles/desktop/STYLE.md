# 复古桌面 · RETRO DESKTOP

> 家族：剪辑与纪实　|　档位：基础档 · 0 积分　|　风格图：`still.jpg`　|　样片源码：`_samples/styles5_film.js → desktop()`

**一句话**：1-bit 灰点阵桌面，黑白窗口和对话框，光标就是视线，最后把「木头」图标拖进北门文件夹。

| 项 | 写法 |
|---|---|
| 导演意图 | 窗口就是镜头，光标就是视线：把一件事演成一次桌面操作。 |
| 材质 / 画法 | 点阵灰桌面（repeating-conic 4px）、白底黑边窗口 + 条纹标题栏 + 硬投影、开窗时 4 层虚线框放大（经典缩放动画）、SVG 箭头 / 沙漏光标。 |
| 配色逻辑 | 只用黑 #000、白 #FFF、两档灰 |
| 字体 | GeistMono 菜单栏 + NotoSC 粗体正文 |
| 动态 | 开窗缩放框 0.22 秒；正文 16 字/秒打字；光标缓动移到按钮；等待时变沙漏；按钮按下反色 0.15 秒；拖图标进文件夹，文件夹闪两下。 |
| 镜头语法 | 锁定（桌面就是画框）。 |
| 声音 | 点击、软驱咔咔、系统提示音。 |
| 标志镜头 | 「⚠ 悬赏已更新：赏金 → 50 金」对话框弹出，光标点「搬」，把木头图标拖进北门文件夹。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：换成 Win95 灰蓝配色、换对话框文案
- **一改就变味**：用彩色、圆角、阴影模糊
- **不能改**：去掉光标

## 搭配
- 适合母版：一条主线 D、闯关 E
- 不适合：古典诗词、情绪向
- 增强档 Renoise 前缀：`（基础档不需要）`
