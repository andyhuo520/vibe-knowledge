# 古风 · GUFENG

> 类别：视觉系统　|　风格图：`still.jpg`　|　样片源码：`_samples/styles_film.js → gufeng()；场景 _samples/scenes_base.js；完整成片 第 01 期`

**一句话**：夜色赭黑的城门与人群剪影，朱红印章和金色数字，像翻开一本暗调的历史绘本。

| 项 | 写法 |
|---|---|
| 导演意图 | 让观众觉得「这是真事、很久以前、有分量」。 |
| 材质 / 画法 | 扁平剪纸剪影，三层景深（远天际线、中城门、近人群），基础档 SVG 手画；增强档换 Midjourney 电影感场景图（同色调）。 |
| 配色逻辑 | 底 #140d0b · 文字 #f3e6cc · 朱红 #d9472b（警示、印章）· 金 #e2b45a（数字、强调）。暗部压到近黑，只给门洞、灯笼一处暖光。 |
| 字体 | NotoSC 900 关键词；竖排古文用纸底 vquote；数字 Geist。 |
| 动态 | 慢推拉（每镜 8% 以内）、印章「啪」地砸下（1.6→1 缩放 0.18 秒）、数字滚动。 |
| 镜头语法 | 固定机位推拉为主，换场景用淡入淡出；不做快速甩镜。 |
| 声音 | 古筝 / 太鼓 / 编钟；钟声做片名，木头落地、金币做关键点。 |
| 标志镜头 | 朱红「没人动」印章砸在画面上；竖排古文逐字显出。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：配色在暗赭体系里换主色、字号、印章文案、乐器
- **一改就变味**：改成亮底（会失去夜色厚重感）、改成写实（变成增强档）
- **不能改**：去掉剪影和三层景深（那就不是古风了，换 paper 或 investigation）

## 搭配
- 适合母版：B 两难选择片（最佳）、D 一条主线片
- 不适合：抽象数学概念
- 增强档 Renoise 前缀：`Cinematic matte painting, Warring States era Qin China, muted ochre/charcoal with vermilion accents, low dramatic sunlight, haze, figures as silhouettes with no facial detail, film grain, no text`
