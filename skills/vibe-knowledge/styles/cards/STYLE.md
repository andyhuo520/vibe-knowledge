# 卡牌对战 · CARD BATTLE

> 家族：游戏　|　档位：基础档 · 0 积分　|　风格图：`still.jpg`　|　样片源码：`_samples/styles6_film.js → cards()`

**一句话**：绿绒桌面上卡牌翻面打出：「赏金 10」攻击「怀疑」被弹开（MISS），打出「×5」后击碎怀疑翻出「信」。

| 项 | 写法 |
|---|---|
| 导演意图 | 把抽象的力量对比变成卡牌数值对撞，赢在哪一张牌一目了然。 |
| 材质 / 画法 | 绿绒径向底 + 虚线牌桌；CSS 3D 翻牌（preserve-3d + backface-hidden）；卡面：标题、插画区、底部数值；攻击光束。 |
| 配色逻辑 | 桌 #0F3B2E · 卡面奶白 #FDF7E8 · 金边 #E9C46A · MISS 红 #FF5A4E |
| 字体 | NotoSC 900 卡名 + Geist 数值 |
| 动态 | 卡牌翻面 0.4 秒；出牌从下方滑入；攻击光束 0.25 秒；被挡住时目标卡抖动 + MISS 弹出；增益卡落下、数值变化、发光；目标卡翻转。 |
| 镜头语法 | 锁定俯视。 |
| 声音 | 洗牌、出牌拍桌、攻击嗖、MISS 叮、胜利号角。 |
| 标志镜头 | 「赏金 ATK 10」打在「怀疑 DEF ？？」上弹出 MISS；加「×5」后怀疑卡翻成金色「信」。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：换卡名和数值含义
- **一改就变味**：数值随意编造成「真实数据」（只能是比喻）
- **不能改**：去掉对撞（只摆卡不打）

## 搭配
- 适合母版：两难选择 B、痛点原理 C
- 不适合：诗词、文化
- 增强档 Renoise 前缀：`（基础档不需要）`
