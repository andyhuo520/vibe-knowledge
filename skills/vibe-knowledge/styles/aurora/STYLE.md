# 极光 · AURORA GLASS

> 家族：暗场概念　|　档位：基础档 · 0 积分　|　风格图：`still.jpg`　|　样片源码：`_samples/styles6_film.js → aurora()`

**一句话**：深海军蓝底上紫青粉光斑缓慢流动，毛玻璃卡片一层层浮上来，数值卡在高潮时描边发光。

| 项 | 写法 |
|---|---|
| 导演意图 | 现代产品 UI 的玻璃拟态：信息像界面卡片一样浮现，背景光在呼吸。 |
| 材质 / 画法 | 4 个大光斑（径向渐变 + blur 60px）缓慢漂移缩放；玻璃卡片 backdrop-filter blur 26px + 细白边 + 投影。 |
| 配色逻辑 | 底 #070B1E · 紫 #7B5CFF · 青 #2EE6D6 · 粉 #FF5EAE · 蓝 #3A7BFF · 卡片白 9% |
| 字体 | Geist / PingFang 600–800 |
| 动态 | 卡片 eOutQuint 上浮 0.5 秒 + 轻微漂浮；数值滚动；高潮描边变暖色并脉动发光；状态红点呼吸。 |
| 镜头语法 | 锁定。 |
| 声音 | 柔和电子 pad、UI 提示音。 |
| 标志镜头 | 「赏金」玻璃卡数字从 10 滚到 50，描边亮成暖金色。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：换光斑配色、换卡片布局
- **一改就变味**：卡片不透明（失去玻璃感）
- **不能改**：光斑静止

## 搭配
- 适合母版：猜谜概念 A、痛点原理 C
- 不适合：古代史
