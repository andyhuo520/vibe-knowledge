# 档案灯台 · LIGHT TABLE

> 家族：剪辑与纪实　|　档位：基础档 · 0 积分　|　风格图：`still.jpg`　|　样片源码：`_samples/styles9_film.js → lighttable()`

**一句话**：暗房里一张冷光灯台，竹简、胶片条、现场照片摊在上面，放大镜依次滑到关键字，红色油性笔圈住。

| 项 | 写法 |
|---|---|
| 导演意图 | 像考古学家在灯台上看原件：放大镜就是镜头，红圈就是结论。 |
| 材质 / 画法 | 灯台（冷白渐变 + 网格 + 外发光）+ 代码竹简（竖排原文）+ 胶片条 + 现场照片（复用配图，标 AI 示意）+ 证据标签；放大镜 = 竹简的 2 倍克隆放在圆形遮罩里。 |
| 配色逻辑 | 暗房 #0A0D14 · 灯台 #F4F9FF → #DCEBFA · 竹 #B98A50 / #D8AE72 · 红笔 #E0302A · 标签黄 #FFE14D |
| 字体 | 宋体 700 竖排（竹简），GeistMono（证据标签） |
| 动态 | 放大镜在关键字之间 0.2 秒滑动（eInOutCubic），停住后红笔 0.4 秒画圈。 |
| 镜头语法 | 锁定俯视（放大镜代替推镜）。 |
| 声音 | 灯台电流嗡、纸张、记号笔划过。 |
| 标志镜头 | 放大镜停在竹简「五十金」三个字上，旁边红圈已经圈住「莫敢徙」和「予十金」。 |

## 能改到什么程度（改成「我的风格」时用）
- **放心改**：换材料（简牍 / 碑拓 / 档案）
- **一改就变味**：竖排字距算错（放大镜对不准）
- **不能改**：放大内容和原件不一致

## 搭配
- 适合母版：两难选择 B、一条主线 D
- 不适合：抽象概念
- 增强档 Renoise 前缀：`（基础档不需要；现场照片可复用增强档配图）`
